# Cube Bomber

[Играть](https://blumbutta.github.io/cube-bomber/)

3D-бомбермэн с киберпузиками на поверхности киберпанк-куба. Шесть связанных граней 8 × 8, один игрок и пять ботов. Всё работает в браузере, без сервера и внешних загрузок во время игры.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD / стрелки |
| Бомба | Пробел |
| Пинок своей бомбы | Поставить, отойти, затем шагнуть обратно на бомбу |
| Повернуть обзор | Q / E |
| Пауза | P / Esc |
| Новая партия после окончания | R / Enter |

На телефоне доступны крестовина и кнопка бомбы. Музыка играет уже в меню, если браузер разрешает автозапуск; иначе включается первым нажатием на странице. Кнопка динамика отключает музыку и эффекты. В меню можно выбрать Люми, Бубо, Зипа, Пипа, Вольта или Физзи: у каждого свой голос. Нажатие на карточку проигрывает голос, выбор сохраняется для следующих партий. При уходе со страницы партия приостанавливается.

## Механика

- После «Начать игру» идёт отсчёт 3–2–1. Боты, движение и таймеры ждут окончания отсчёта.
- Пламя начинает задевать входящего персонажа после 20% шага; с покидаемой клетки оно уже не достаёт после 80% шага. Порог считается по положению в анимации и одинаков для игрока и ботов; такой же допуск действует при обрушении грани.
- Итог показывает место по порядку выбывания (от 6-го до 2-го), последнему выжившему — «Победа!». При одновременной гибели место общее.
- Каждые 2 минуты игрового времени отрывается одна грань. Первая выбирается случайно, последующие — среди соседей предыдущей; оставшаяся арена сохраняет связность. Последняя грань остаётся для финальной схватки.
- За 10 секунд до обрушения грань мигает красным и звучит посекундный отсчёт. Боты стараются уйти. При падении звучат треск металла и гул; оставшиеся на грани персонажи погибают. На исчезнувшую грань нельзя перейти, пламя через неё не проходит. У скрытых от камеры рёбер появляется слабая красная стенка; спереди остаётся виден открытый край.
- У каждой грани 64 клетки. На чётной сетке центр расположен между четырьмя клетками; старт — в одной из этих четырёх клеток, с открытой центральной зоной.
- Рёбра связывают соседние грани геометрически: направление персонажа, бомбы и огня поворачивается при пересечении ребра.
- Камера плавно переходит на новую грань за 0,5 секунды. На время перехода движение игрока задерживается, таймеры бомб продолжают идти.
- Бомба взрывается через 2,7 секунды, пламя существует 0,75 секунды. Стартовая дальность — 1 клетка в каждом из четырёх направлений.
- Пламя переходит на соседние грани с оставшейся дальностью, останавливается у стен и после первого кирпича, подрывает бомбы любого владельца. Для катящихся бомб контакт с огнём и центр взрыва считаются по их видимому положению, в том числе при пересечении ребра.
- Пинок действует только на собственную бомбу. Она катится со скоростью 3 клетки в секунду, в том числе через рёбра, до препятствия, бомбы или персонажа. Пинок не продлевает фитиль.
- Стартовая скорость игрока и всех ботов одинакова — около 3,3 клетки в секунду. Бонусы скорости действуют одинаково. Разрушаемые кирпичи оранжевые, со светящимся крестом; неразрушаемые стены — тёмный металл с голубыми линиями.
- Кирпичи могут скрывать бонусы скорости (до 4 уровня), дальности (до 12 клеток) и количества одновременно установленных бомб (до 5).
- Среди выпавших бонусов 65% увеличивают количество бомб, 20% — скорость, 15% — дальность. Скорость растёт на 7% от базовой за бонус, не более чем на 21% суммарно.
- Начальная площадка 2 × 2 окружена плотной застройкой. До перехода на соседнюю грань нужно расчистить хотя бы один кирпич.
- Красные клетки показывают текущий след будущего взрыва, включая продолжение на других гранях. У движущейся бомбы след перемещается вместе с ней; это подсказка текущей позиции, а не предсказание места остановки. Все персонажи и бомбы видны на развёртке куба.
- Побеждает последний выживший. Огонь своей бомбы тоже опасен.
- После гибели игрока киберпузик кувыркается и растворяется в неоновых частицах 3 секунды. Боты, бомбы и взрывы продолжают работать всё это время, затем появляется меню результата.

Персонажи и окружение построены из 3D-геометрии. Музыка, эффекты и мультяшные голоса синтезируются через Web Audio; записи из телешоу не используются.

## Разработка

Node.js 24 и pnpm 10:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run build
python3 -m http.server 4186 --directory dist
```

Исходники: `src/cube-bomber/engine.js` (правила и ИИ), `main.js` (3D и интерфейс), `audio.js` (звук). Статическая страница находится в `dist/`. GitHub Actions проверяет тесты, собирает JavaScript и публикует `dist/` в Pages при обновлении ветки `main`.

Тесты проверяют все 1536 шагов по поверхности, все 24 направленных ребра, сохранение направления управления, дальность и цепные взрывы, пинки, бонусы, ботов и конец партии.
